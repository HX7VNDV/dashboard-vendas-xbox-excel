# Dashboard de Vendas Xbox

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de Excel, com o objetivo de transformar uma base de dados de vendas e assinaturas em um dashboard interativo para análise de desempenho comercial.

A solução organiza os dados, realiza cálculos automáticos e apresenta os principais indicadores por meio de cards, filtros e gráficos.

## Objetivo

Transformar dados brutos de assinaturas em informações visuais que facilitem a identificação de padrões, comparação de resultados e análise do desempenho das vendas.

## Dashboard

O painel apresenta indicadores como:

* Faturamento total
* Quantidade de assinaturas
* Ticket médio
* Renovação automática
* Cupons concedidos
* Receita por plano
* Distribuição por periodicidade
* Receita de produtos adicionais
* Evolução mensal do faturamento

## Interatividade

O dashboard possui seletores que permitem analisar os resultados por:

* Plano
* Periodicidade da assinatura

Os indicadores filtrados são atualizados de acordo com a seleção realizada.

## Estrutura do arquivo

### Base

Contém os registros originais utilizados no projeto.

### Cálculos

Concentra os cálculos, indicadores e tabelas auxiliares utilizados pelo dashboard.

### Dashboard

Apresenta os principais resultados em uma interface visual e interativa.

## Principais análises

O projeto permite responder perguntas como:

* Qual é o faturamento total?
* Qual plano possui maior participação no faturamento?
* Como as assinaturas estão distribuídas?
* Qual é o ticket médio?
* Qual é a participação da renovação automática?
* Quanto os produtos adicionais representam em receita?
* Qual é o impacto dos cupons?
* Como o faturamento evoluiu ao longo do período?

## Como utilizar

1. Faça o download do arquivo `Dashboard_Vendas_Xbox_INTERATIVO.xlsx`.
2. Abra o arquivo no Microsoft Excel.
3. Acesse a aba `Dashboard`.
4. Utilize os filtros disponíveis para explorar os indicadores.
5. Consulte as abas `Base` e `Cálculos` para visualizar os dados e a lógica utilizada.
